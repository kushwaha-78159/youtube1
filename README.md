# Kushwaha Academy 📚

A complete dynamic website built with Flask, PostgreSQL, and Bootstrap for managing educational content, articles, blogs, stories, NISM mock tests, and video courses.

## 🚀 Features

### 📝 Content Management
- **Articles** - Write and publish articles in Hindi/English with Markdown support
- **Blogs** - Share blog posts with categories and thumbnail images
- **Stories** - Publish inspirational stories with multilingual support

### 📚 NISM Mock Test System
- Book-wise test organization
- Chapter-wise questions
- Multiple choice questions with 4 options
- Instant result calculation
- CSV upload support for bulk questions

### 🎓 Courses
- YouTube video integration
- Course descriptions
- Easy video management

### 👥 User System
- User registration with profile images
- Secure login system
- Role-based access (Admin/User)

### 🔧 Admin Panel
- Complete CRUD operations for all content types
- Dashboard with statistics
- User management
- Bulk question upload via CSV

## 🛠️ Technology Stack

- **Backend**: Flask (Python)
- **Database**: PostgreSQL / SQLite
- **Frontend**: HTML5, CSS3, Bootstrap 5
- **Authentication**: Flask-Login
- **Markdown Support**: Python-Markdown
- **File Uploads**: Werkzeug

## 📋 Prerequisites

- Python 3.8+
- PostgreSQL (optional - SQLite works too)
- pip (Python package manager)
